STAR Executive Brief

Technical Interview Overview
SITUATION

Enterprises are deploying autonomous AI agents and MCP servers with real database access, but a single hallucinated DROP, unbounded DELETE, or unauthorized permission grant can destroy production environments. Existing controls act before (IAM) or after (logs); nothing verifies actions during execution. Regulation (EU AI Act Article 14) mandates human oversight and explainability with penalties up to €35M.

TASK

Architect an enterprise runtime security gateway capable of intercepting, risk-scoring, auditing, and automatically rolling back autonomous agent operations in flight with sub-100ms latency, zero credential leakage, and non-repudiable audit evidence.

ACTION

Built AgentGuard: a hub-and-spoke security gateway deployed as a Databricks App (FastAPI). Engineered a 6-checkpoint pipeline (policy, scope, 0–100 risk scoring, human gating, snapshot, and post-exec verify), an AST SQL firewall (sqlglot), a 3-strategy OAuth On-Behalf-Of (OBO) token broker, an append-only SHA-256 hash-chained audit ledger, and a 3-tier Delta Time Travel Saga rollback engine.

RESULT

Blocked 100% of destructive operations at ~30–80ms overhead with zero credential sharing. Shipped ~9K LoC prod + ~5.8K LoC tests (268+ tests) with a formal security review. Directly addresses AI Dev Kit issue #372 and provides automated compliance evidence for EU AI Act Art. 14 and SOC 2.

02 // The 6-Stage Execution Pipeline

Every agent query passes through sequential, short-circuiting inspection checkpoints before touching production tables.

1. Policy Check

<10MS • BLOCKLIST

Evaluates hard global blocklists and workspace rules. Instantly blocks 8 destructive classes (e.g. DROP DATABASE, TRUNCATE, GRANT ALL).

action IN GlobalBlocklist ⇒ REJECT(403)

2. Scope Boundary

<20MS • BLAST RADIUS

Matches operation against 7 role templates (from read_only to full_access). Default-deny: operations outside task scope fail closed.

verify_blast_radius(task_id, target_tables)

3. Risk Scoring

<30MS • 0–100 SCORE

Calculates weighted score across 6 factors: action type (30%), blast radius (25%), environment (25%), time (10%), data sensitivity (10%), and behavior.

score ≥ 35 → FLAG; score ≥ 90 → BLOCK

4. Human Gate

EU AI ACT ART. 14

High-risk operations trigger asynchronous human approval. Generates explainable intent summaries so operators understand risk before approving.

if score ≥ threshold: await_approval()

5. State Snapshot

PRE-EXEC CAPTURE

Snapshots Delta table version (table_changes) and object metadata before execution. Pre-requisite for deterministic reversibility.

snapshot_version = DeltaTable.history(1)

6. Post-Exec Verify

SAGA AUTO-ROLLBACK

Verifies modified row counts and schema mutations against expected scope. Automatically executes compensating Saga rollback if unexpected drift occurs.

RESTORE TABLE t TO VERSION AS OF v_prev

03 // Zero-Trust Identity & Forensics Layer

Solving the confused-deputy problem within Databricks Apps OAuth constraints while guaranteeing tamper-evident audit trails.

Confused-Deputy Solution Universal Identity Bridge & Hash-Chained Audit Ledger

By default, Databricks Apps execute queries using the App's own service principal—destroying individual agent identity and masking who authorized a command. AgentGuard introduces a 3-strategy token broker with zero credential sharing:

1. Forwarded Token → 2. Dual-Header Fallback → 3. create-obo-token (OBO PAT Minting) → 4. SHA-256 Hash-Chained Ledger

Tamper-Evident Guarantee: Every audit event stores sha256(prev_hash || current_event) written via an INSERT-only stored procedure. Modifying historical rows breaks the mathematical chain, providing verifiable proof of non-tampering for SOC 2 and regulatory auditors.

04 // Architectural Safeguards & Systems Design

Key engineering decisions that ensure AgentGuard is fast, unbypassable, and resilient to failure.

Read-Only AST Parsing (sqlglot)

Inspects SQL syntax trees to catch subqueries, CTEs, and tautologies (WHERE 1=1) without rewriting queries, avoiding the risk of query corruption.

Defense-in-Depth vs. Sole Control

AgentGuard does not replace Unity Catalog RBAC. Using OBO tokens, Unity Catalog still enforces underlying permissions—ensuring a bug in policy code never grants unauthorized access.

Deterministic AST Backstop

LLMs provide intent explanations and suggest templates, but hard blocking is enforced by deterministic AST rules to prevent prompt-injection bypasses.

3-Tier Saga Rollback Handling

Tier 1 (Delta Restore), Tier 2 (Config Recreate), and Tier 3 (Audit-Only). Surfaces exact recovery state during half-failures rather than assuming rollback succeeded.

STAR Executive Brief

Technical Interview Overview
SITUATION

Registering carbon-credit projects requires drafting complex Project Design Documents (PDDs) citing 134 rigidly templated methodologies with strict baseline and additionality proof. Over 1,500 registered PDDs exist publicly on the Verra registry as high-value precedent, but pure vector search consistently fails on dense regulatory text and exact methodology tokens (e.g. VM0042).

TASK

Architect an enterprise-grade RAG and agent drafting platform capable of answering complex standards queries with verifiable citations, generating draft PDD sections grounded in registered precedent, and measuring retrieval/generation quality via a rigorous evaluation suite.

ACTION

Engineered an end-to-end pipeline: layout-aware PDF parsing via Docling (512-token chunks with context-prefix embeddings); Dense + BM25 hybrid search fused via Reciprocal Rank Fusion (RRF, k=60); candidate rescoring with a cross-encoder reranker; and a LangGraph agent managing cyclic extraction, intent routing, and section-by-section drafting.

RESULT

Eliminated semantic search blindness on exact methodology identifiers while preserving semantic recall for conceptual clauses (e.g. additionality). Shipped a comprehensive 28-test evaluation harness covering context precision/recall, faithfulness, answer relevancy, and adversarial prompt robustness.

02 // Multi-Stage Hybrid Retrieval & Reranking

Why pure vector search fails on regulatory documents and how combining dense, sparse, and cross-encoders creates optimal precision.

1. Layout-Aware Docling Chunking

STRUCTURE PRESERVATION

PDDs contain nested sections and complex parameter tables. Docling's HybridChunker parses PDF layout natively (512 tokens / 50 overlap) rather than blindly splitting character tokens mid-table.

chunk = docling.HybridChunker(max_tok=512, overlap=50)

2. Context-Prefix Embedding

SEPARATE EMBED VS DISPLAY

Chunks are enriched with project metadata, section headers, and methodology tags in text_for_embedding to maximize vector recall, while clean original text is fed to the LLM.

text_for_embedding = f"[{meta}] " + clean_text

3. Reciprocal Rank Fusion (RRF)

SCALE-FREE RANK FUSION

Fuses incomparable cosine scores (0 to 1) and unbounded BM25 scores. Rank damping parameter k=60 prevents single-list domination:

RRF(d) = Σ 1 / (60 + rank(d in list_i))

4. Cross-Encoder Reranker

QUERY-DOC ATTENTION

Bi-encoders retrieve 40 candidates cheaply; ms-marco-MiniLM-L-6-v2 rescores query-document interaction expensively, filtering to the top 5 high-precision chunks.

score = CrossEncoder(query, chunk_text) → Top 5

03 // LangGraph State Machine & Section Drafting

Moving beyond simple Q&A: managing multi-turn state, parameter collection cycles, and section-by-section document drafting.

LangGraph Agent Cyclic Information Extraction & Section Generation

Drafting a 100-page regulatory filing in a single prompt exceeds context coherence and causes hallucinated methodology claims. The LangGraph state machine decomposes the task into a structured lifecycle:

1. Intent Router → 2. Parameter Collector (Cyclic Loop) → 3. Precedent Retrieval → 4. Section Generator → 5. Consistency Summarizer

Consistency Across Sections: As each section is generated, a concise summary is passed into subsequent section prompts alongside retrieved precedent, maintaining terminology alignment while preventing context window saturation.

04 // Architectural Safeguards & Systems Design

Key engineering decisions that ensure the RAG system is hallucination-resistant, scalable, and verifiable.

Hybrid Justification: VM0042 vs. Additionality

Semantic embeddings fail on rare, arbitrary tokens like VM0042 (which BM25 retrieves easily via high IDF). Conversely, BM25 fails on semantic concepts like additionality where dense vectors excel.

Two-Stage Retrieval Cost Trade-Off

Bi-encoders pre-compute millions of chunk vectors offline. Cross-encoders cannot be pre-computed, so running them only on the top 40 candidates delivers cross-encoder precision at bi-encoder cost.

Diagnostic RAGAS Metric Separation

Low faithfulness with high context precision isolates an LLM hallucination bug. High faithfulness with low context recall isolates a retrieval/chunking bug.

Checkpointed Multi-Turn Persistence

Utilizes MemorySaver checkpointers keyed by thread_id to maintain conversational and extraction state across multi-turn user interactions.
